Project instructions for Claude Code.

## Incident Logging

When a bug is fixed or an incident is resolved, add an entry to `docs/INCIDENT_LOG.md`.

**Rules:**
- Every entry must include the date, time, and timezone of each event
- Every entry must include the relevant commit hash(es)
- No existing entry may be edited or deleted — the log is append-only
- New incidents go at the bottom of the file, following the established format
- Each entry must document: symptom, root cause, timeline of changes, prevention, and files involved
